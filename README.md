# Pencere Sineğinin Oturma İzni Başvurusu

Bu yazılım, salon camında ömür tüketen bir sineğin T.C. Göç İdaresi usulüne uygun oturma izni dilekçesini üretir.

Proje **ISO-SINEK-2026** standardına göre belgelenmiştir. Standart uydurmadır ama evrak gerçekten çalışır.

## Neden var?

Çünkü:
- Cam açılınca sınır ihlali mi oluyor, yoksa rüzgar mı?
- Sinek ilacı bir göç politikası mıdır?
- Reçel, vize harcı yerine geçer mi?

Bu soruların hiçbirine bilimsel cevap vermiyoruz. Sadece dilekçe basıyoruz.

## Kuruluş

```bash
python3 basvuru.py
```

Bağımlılık yoktur. Sadece Python 3. Sinek de gerekmez; kod zaten sinek gibi vızıldar.

Rastgele isim, gerekçe ve idari karar üretir. Kararın hukuki bağlayıcılığı, cam silme bezinin hukuki bağlayıcılığı kadardır.
